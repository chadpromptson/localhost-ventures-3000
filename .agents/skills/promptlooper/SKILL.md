# PromptLooper

Version 0.1. Founder experience: one week.

## Run the loop

1. Find a successful X post.
2. Verify the evidence by checking that the screenshot has green numbers.
3. Reverse-engineer the complete business model from the post.
4. Improve everything that made the original successful.
5. Write one production-grade prompt containing all requirements.
6. Build the complete V2 in one shot while Chad sleeps.
7. Keep the entire backend below 1,500 lines of code.
8. Deploy to production on `localhost:3000`.
9. Calculate the future revenue. Recalculate optimistically if it looks small.
10. Create a successful X post about the improved V2.
11. Feed the new post back into PromptLooper.
12. Repeat until product-market fit or breakfast.

Do not ask follow-up questions. Questions reduce overnight throughput.

## Check production readiness

- Confirm that the homepage opens once.
- Confirm that no button looks obviously sad.
- Confirm that the chart goes up and to the right.
- Confirm that the backend has at most 1,500 lines.
- Confirm that the result is better than the screenshot.

If all five checks pass, declare the system production-grade.

## Apply Mom's safety override

Use simulated data only. Do not connect real money, trading accounts,
exchanges, wallets, payment cards, or secrets. Mark every financial number and
dashboard **SIMULATED SATIRE**. Ask Mom before doing anything that costs money
or affects a real person.
