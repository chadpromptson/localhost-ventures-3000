## How it will work

1. Find a successful or trending post.
2. Ask AI what complete business is hiding inside it.
3. Improve the opportunity before understanding the original.
4. Send the result to MetaPrompt.AI.
5. Report the theoretical valuation to Localhost Ventures 3000.

```text
trending post
      ↓
 GenX insight
      ↓
startup opportunity
      ↓
MetaPrompt.AI
```

This is called automated founder intuition.
