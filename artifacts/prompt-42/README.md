# Prompt #42 Artifacts

## Purpose

This folder publishes the exact operating instructions used by Prompt #42 at specific
points in the Localhost Ventures 3000 engineering history.

Published version files are immutable records. Prompt #42 can learn new engineering
words, but a changed prompt must be added as a new version instead of silently
rewriting an earlier one.

## Versions

- [System Prompt v0.1](system-prompt-v0.1.md) — the original One-Shot Optimist
  configuration Chad considers complete and production-grade.

Versions v0.2 through v1.0 are part of Prompt #42's planned growth arc. Their exact
artifact files will be added only after their complete contents have been established.
